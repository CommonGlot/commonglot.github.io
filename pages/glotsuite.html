Impact & Adoption

GlotSuite tools are used by major projects worldwide

  • FineWeb2 uses GlotLID as a core component for language identification in its web-scale data pipeline.
  • MaskLID builds on GlotLID's language label set and architecture for improved language detection.
  • NLLB (No Language Left Behind) benefits from GlotSuite's language coverage analysis and script identification.
  • MADLAD-400 leverages GlotLID for identifying and filtering multilingual web data.
  • CulturaX uses GlotLID for language identification in their cleaned CommonCrawl corpus.
  • Research groups at Google, Meta, Microsoft and many universities use GlotSuite tools in their multilingual NLP pipelines.
